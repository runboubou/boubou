# Security

Please report vulnerabilities privately through
[GitHub's private reporting](https://github.com/runboubou/boubou/security/advisories/new),
not in a public issue.

Boubou downloads and runs model servers and native binaries, so issues in
download verification, cache handling, the bundled runtimes or the audio helper
are in scope.

Include the Boubou version or commit, your macOS version, the model ID, the
impact and the smallest steps that reproduce it. Leave out recordings,
transcripts and personal data.

Fixes go into `main` and the next release. Older versions are not patched.
